# ORBITFIT 🚀 — Microgravity Exercise Companion

NASA Space Apps 2026 · Health Monitoring Software challenge.

Today view with anatomical muscle map, workout timer, workout logging, daily/weekly/periodic health checks (HR, SpO₂, fatigue, nutrition, grip strength, ultrasound, bone density), rule-based tips and exercise suggestions, light/dark mode, CSV export.

```bash
npm install
npm run dev
```

Volume = Sets × Reps × Resistance is a logging metric, not a validated measure of adaptation. ORBITFIT does not diagnose, prescribe, or guarantee prevention of muscle atrophy or bone loss.
